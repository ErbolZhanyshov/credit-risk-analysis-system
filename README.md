# AI Credit Risk Analysis System

This project is a machine learning based credit risk analysis and loan approval prediction system.

## Features

* Credit Risk Prediction
* Loan Approval Prediction
* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Model Comparison
* ROC Curve
* Confusion Matrix
* Explainable AI
* Streamlit Web Application

## Technologies

* Python
* Scikit-learn
* Pandas
* Streamlit
* Matplotlib
* Seaborn
